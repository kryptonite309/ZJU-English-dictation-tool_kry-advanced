# 大英默写器 · KRY 增强版

这是基于 [Lucent-Snow 的 ZJU 大英默写器](https://github.com/Lucent-Snow/ZJU-English-dictation-tool) 制作的 Windows 个人增强版。原项目使用 PyQt6，本版本使用 C# 和 Windows Forms，保留自由练习，并补充每日学习、单词本管理与个性化设置。本项目不是原项目的官方版本。

这个仓库保存增强版源码，以及供校内学习使用的 `book2`、`book3` 词书。可执行程序通过 Releases 提供，仓库不包含任何人的学习记录。

## 下载

普通用户可以从 [Releases](https://github.com/kryptonite309/ZJU-English-dictation-tool_kry-advanced/releases/latest) 下载最新版本。下载后请完整解压，保持 `main.exe` 与 `data` 文件夹处于同一层，再双击 `main.exe` 启动。

## 主要功能

- v1.2.0 新增独立学习统计看板、听写题型、答错后的字符级拼写差异、四模块独立的顺序/单元内随机/词书内随机、暂停与跨重启精确恢复、有效学习计时、可选的结束列表前备份，以及带 SHA256 校验、完整备份和失败回滚的 GitHub 自动更新。例句、听写、普通拼写可同时启用并调整先后；错题转易错本需要三项门槛同时满足，单词仍只能手动“斩”入已掌握。
- v1.1.8 为全部单词本管理增加“最近编辑优先”排序和最后编辑时间；新学、历史列表复习、错题与易错词复习加入实时进度条，答错不增加进度，复现答对后才计入；新增默认 `Shift+Q` / `Shift+E` 的只读回看翻页快捷键；朗读音量改为可拖动的学习音频总音量滑条，并可供后续学习提示音共用。
- v1.1.7 为单个英文单词的中文释义补充词性，例如 `apple  n. 苹果`；词组不显示词性。多词性可显示为 `n./v.`，旧进度和单词本会自动补齐词性而不改变作答记录。外部词库也可使用 `part_of_speech` 或 `pos` 列指定词性。
- v1.1.6 将词库中按不同释义拆行的同一英文合并为一个逻辑单词，保留全部释义并去除完全相同的例句。合并后若有多条不同例句，新学、复习和自由练习会让每条例句都出现，全部完成后才算例句题完成，而每词每列表仍只计一次。旧学习列表会保留已做例句，只补做未出现的例句；同名词共用错题、易错和已掌握状态，手动“斩”后不会从另一条同名记录再次出现。
- v1.1.5 修复圆角按钮在灰色卡片上露出黑色矩形底框的问题。按钮窗口本身按圆角裁剪，并使用所在容器的实际背景色绘制边缘。
- v1.1.4 彻底关闭自绘圆角按钮残留的 Windows 原生焦点框和默认按钮外框，并为按钮文字增加内边距，修复按钮边缘出现白色虚线或残缺边框的问题。
- v1.1.3 中，如果例句输入框已有内容，按 Enter 会直接提交答案；空输入时才逐层显示提示。圆角按钮的焦点边框也已统一修复，项目与联系方式可在软件“帮助”中查看。
- v1.1.2 已为全部例句填空加入统一的分阶段提示。题目开始时不直接显示首字母；默认按 Enter 后显示首字母，再按一次显示中文释义，最后一次才提交。该功能覆盖新学、历史列表复习、错题与易错词复习和自由练习，首字母开关与操作键均可在设置中修改。
- v1.1.1 已修复例句填空的词形判定。例句题按照当前句中实际隐藏的形式作答，例如词条 `unlearn` 在 `start by [[unlearning]]` 中应填写 `unlearning`；普通拼写题仍填写 `unlearn`。
- 自动备份会排除 Git 内部元数据，并能正常轮换包含只读文件的旧备份。

- 每日学习分为新词学习、历史提取列表复习、错题与易错词复习。三个部分相互独立，未完成时会在各自入口显示“继续”，也可以手动结束当前列表；结束后只保留已经完成的词，未完成词返回原来的候选范围。
- 新词先展示单词，再展示例句和释义，之后可按自定义顺序进入例句填空、听写和普通拼写。答错的词会在当前列表中复现，直到答对；答错时会显示字符级差异。展示和答题阶段均可回看本阶段已过的内容，回看不会修改答案。
- 错题本、易错本和已掌握单词本可以在设置中管理。错词转入易错本的正确次数可调整；“斩词”会将当前词移入已掌握，并排除后续题目。
- 可按词书选择新词数量；新学、历史列表复习、错题复习和自由练习可分别使用顺序、单元内随机或词书内随机。学习日的切换时间、复习列表数量和答题规则都可调整。统计看板和大日历可以查看区间指标、趋势、每天的学习记录和对应列表。
- 未完成列表重新进入时会立即使用最新题型设置。设置中的“词书管理”可以导入外部 CSV、创建新词书或向已有词书添加单元，并可重命名词书。
- 可调整练习文字的字体、字号、颜色、提示文案，以及各学习界面的纯色或图片背景。
- 新词展示和听写可调用 Windows 本机英语语音离线朗读。听写提交后会同时显示正确英文和中文；没有英语语音时会先提示安装语音或临时关闭听写。
- 支持撤销、手动备份和定时自动备份。自动备份默认每 10 分钟一次，最多保留 6 份；手动备份单独保存。
- 学习窗口支持暂停、跨重启精确恢复和独立有效计时；程序支持经过 SHA256 校验、完整备份与失败回滚的 GitHub Release 自动更新。

## 构建与运行

程序面向 Windows x64，使用 .NET Framework 4.x。构建时需要系统提供 C# 编译器和 `System.Speech`。在 PowerShell 中进入源码目录，执行下面的命令。

```powershell
.\build.ps1
```

默认构建结果保存在源码目录上一级的 `_build/main.exe`。运行前，把 `main.exe` 放到一个自己有写入权限的文件夹，并在同一层准备 `data` 词书目录。不要直接在压缩包里运行程序。

```text
程序文件夹/
  main.exe
  data/
    parts_of_speech.csv
    book2/
      unit1-1.csv
    book3/
      unit1-1.csv
```

每个 CSV 至少包含 `english` 和 `chinese` 两列，也可以包含 `examples`、`part_of_speech`（或 `pos`）列。仓库附带的 `book2`、`book3` 词书用于浙江大学学生之间的学习交流。自行添加其他词书时，请确认相应内容的使用和分享权限。

学习记录、错题本、外观设置与备份保存在程序所在文件夹。移动程序前，先关闭程序，再备份整个文件夹。旧版 `wrong_words.json` 可在首次启动时迁移；迁移前仍建议自己留一份原文件备份。
