# 大英默写器 · KRY个人增强版

这是基于 [Lucent-Snow 的 ZJU 大英默写器](https://github.com/Lucent-Snow/ZJU-English-dictation-tool) 制作的 Windows 个人增强版。原项目使用 PyQt6，本版本使用 C# 和 Windows Forms，保留自由练习，并补充每日学习、单词本管理与个性化设置。本项目不是原项目的官方版本。

这个仓库保存增强版源码，以及供校内学习使用的 `book2`、`book3` 词书。仓库不包含可执行程序或任何人的学习记录。

## 主要功能

- 每日学习分为新词学习、历史提取列表复习、错题与易错词复习。三个部分可以分别进入，未完成的列表可以继续。
- 新词先展示单词，再展示例句和释义，之后进入例句填空或拼写。答错的词会在当前列表中复现，直到答对。展示和答题阶段均可回看本阶段已过的内容，回看不会修改答案。
- 错题本、易错本和已掌握单词本可以在设置中管理。错词转入易错本的正确次数可调整；“斩词”会将当前词移入已掌握，并排除后续题目。
- 可按词书选择新词数量，按单元顺序或随机抽取。学习日的切换时间、复习列表数量和答题规则都可调整。日历可以查看每天的学习记录和对应列表。
- 可调整练习文字的字体、字号、颜色、提示文案，以及各学习界面的纯色或图片背景。
- 新词展示阶段可调用 Windows 本机英语语音离线朗读。没有可用英语语音时，文字学习仍可使用。
- 支持撤销、手动备份和定时自动备份。自动备份默认每 10 分钟一次，最多保留 6 份；手动备份单独保存。

## 构建与运行

程序面向 Windows x64，使用 .NET Framework 4.x。构建时需要系统提供 C# 编译器和 `System.Speech`。在 PowerShell 中进入源码目录，执行下面的命令。

```powershell
.\build.ps1
```

默认构建结果保存在源码目录上一级的 `_build/main.exe`。运行前，把 `main.exe` 放到一个自己有写入权限的文件夹，并在同一层准备 `data` 词书目录。不要直接在压缩包里运行程序。

```text
程序文件夹/
  main.exe
  data/
    book2/
      unit1-1.csv
    book3/
      unit1-1.csv
```

每个 CSV 至少包含 `english` 和 `chinese` 两列，也可以包含 `examples` 列。仓库附带的 `book2`、`book3` 词书用于浙江大学学生之间的学习交流。自行添加其他词书时，请确认相应内容的使用和分享权限。

学习记录、错题本、外观设置与备份保存在程序所在文件夹。移动程序前，先关闭程序，再备份整个文件夹。旧版 `wrong_words.json` 可在首次启动时迁移；迁移前仍建议自己留一份原文件备份。
